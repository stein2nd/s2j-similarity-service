### 補足 (現行コードから見える前提)

* 本リポジトリは **「純粋な PHP ライブラリ」** としては主要機能が実装済み (類似度計算、Embedding、バッチ、キャッシュ、基本エラー)。
* 公開 API は `S2J\Similarity\...` に統一され、`S2J\SimilarityService\...` (旧 API) は削除済みです (Composer の autoload に過去互換の接頭辞が残っていても、旧クラスは提供しません)。
* `error.type` は `schema/openapi.yaml` と `DomainError::$type` とで snake_case に統一済みです。
* HTTP runtime は WordPress REST API のみ (`register_rest_route`) とし、`adapters/http/wordpress/` に routing、Controller、認証・エラーマッピング・レスポンス整形を実装済みです。**HTTP 統合テスト**は WorDBless 上の `WP_REST_Server` / `rest_do_request()` で実行します (`WordPressRestAdapterIntegrationTest` **14 ケース**)。**README.md** には OpenAPI 論理パスと WordPress 実エンドポイント、プラグインへの組込み、コマンドラインによる REST 呼び出し例、TypeScript SDK の利用手順、および Usage の「OpenAIEmbeddingStrategy オプション」(コンストラクタの公式な簡易リファレンス) が記載されています。
* **`composer.lock`** をバージョン固定のソースとして追跡しており、clone 後は `composer install` でテスト用 WordPress 配置と WorDBless のドロップインまで再現できます。**開発専用**の Composer オートロード (`autoload-dev`) により `tests/Support/` の契約検証クラスが読み込まれます。
* **CI とエンジニアリング品質**: **docs/engineering/ci.md** の「**CI 品質ゲート方針**」が merge 前に満たすべきゲートの規範であり、**.github/workflows/ci.yml** がそのジョブ実装です。PHP 側は **`composer run lint:php`** (PHPStan + PHPCS) と `test:unit` / `test:wordpress` / `phpcbf` が利用可能です。**OpenAPI レスポンス契約検証**は上表の専用行のとおり `test:wordpress` に含まれ、機能一覧では **実装済み / 100%** (**ci.md** で定めた初期スコープ内)。
* **OpenAPI codegen**: `docs/contracts/codegen_spec.md` の Governance に従い、`npm run verify:codegen` と CI の **openapi-codegen** ジョブで生成差分ゼロを検証します。**TypeScript SDK** のビルド・テスト・型チェックは **typescript-sdk** ジョブで実行します (Node **v22.x**)。
* **TypeScript SDK** は npm ワークスペース `packages/ts-client` (`@s2j/similarity-client`) として実装済みです。**docs/interfaces/sdk_spec.md** の「**TypeScript SDK の品質保証の方針**」どおり、Vitest とモック HTTP で公開 API を守り、E2E や runtime スキーマ検証を標準要件とはしません。`tools/generated/ts` は内部実装とし、外部からはラッパーのみを公開面とします。
* OpenAPI には `ErrorResponse` まで定義済みです。**HTTP レスポンスの JSON Schema 機械検証**は **WordPress 統合** で実施済み (詳細は上表「**OpenAPI レスポンス契約検証**」)。**`/v1/similarity` と `/v1/embedding` の成功・代表的な `ErrorResponse` (embedding の検証 **400** を含む)** は初期スコープに含みます。**レスポンスヘッダー** や **スキーマの完全カバー** は **docs/engineering/ci.md** の段階的導入に委ねます。
